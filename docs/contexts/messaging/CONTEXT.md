# Mensagens / Messaging

Mensagens permite o contato privado entre perfis de pessoas e entre uma pessoa e um
Negócio. Anúncios e páginas de perfil podem iniciar esse contato sem se tornarem
participantes da troca.

## Linguagem

**Conversa / Conversation**:
Troca privada entre dois Perfis de usuário ou entre um Perfil de usuário e um Negócio.
Cada par de perfis possui uma única Conversa contínua. Somente as partes envolvidas
podem ler e responder às Mensagens da Conversa.
_Evitar_: Negociação, atendimento, pedido

**Mensagem / Message**:
Texto enviado por uma das partes de uma Conversa à outra. Seu emissor é o perfil que
participa da Conversa, não o Anúncio ou a página usada para iniciá-la.
_Evitar_: Anúncio, notificação

**Bloqueio / Block**:
Restrição criada por uma das partes de uma Conversa que impede novas Mensagens nos dois
sentidos, sem apagar o histórico. A parte que criou o Bloqueio pode desfazê-lo.
_Evitar_: Arquivamento, denúncia

**Denúncia de mensagem / Message Report**:
Sinalização de uma Mensagem por uma das partes para revisão pela equipe. A denúncia
não suspende a Conversa por si só.
_Evitar_: Bloqueio, exclusão

**Arquivamento / Archiving**:
Retirada de uma Conversa da caixa de entrada ativa de uma parte, sem apagar o histórico
nem mudar a caixa de entrada da outra parte. Uma nova Mensagem recebida devolve a
Conversa à caixa de entrada ativa.
_Evitar_: Exclusão, Bloqueio
